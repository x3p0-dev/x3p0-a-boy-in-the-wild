A block theme built for the serialized story A Boy in the Wild.

== Description ==

A Boy in the Wild is a block theme designed specifically for a serialized episodic story told in field notes. It is not a general-purpose theme. Every design decision serves the narrative — a thirty-year story following a boy who survives alone in the wilderness, written as if his field notes are being published one chapter at a time.

The theme is built with WordPress Blocks and makes use of the Interactivity API, canvas-based atmospheric effects, and a custom color palette system with seasonal style variations.
