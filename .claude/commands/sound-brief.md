Use the `abitw-sound-briefs` skill before writing anything.

## Read first

- `.claude/docs/private/story-outline.md` — the outline entry for chapter $1:
  season, time, location, and whether it is a played chapter.
- `.claude/docs/private/story-continuity.md` — sound decisions already made.

## Produce

Decide first whether this chapter wants sound at all — silence is a valid
choice, and the design brief may already have settled it. If it does, produce
a Suno prompt for each sound type the chapter needs (ambient sound effects,
ambient music, or played-chapter music), following the skill's format.
